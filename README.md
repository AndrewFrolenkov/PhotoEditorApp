# 📱 PhotoEditor iOS App

PhotoEditor — это iOS-приложение, реализованное по архитектуре **MVVM**, которое позволяет пользователям редактировать фотографии: рисовать поверх изображения, добавлять текст, масштабировать и поворачивать изображение. Приложение также включает авторизацию через email и Google с использованием Firebase Authentication.

---

## 🧱 Архитектура

Приложение построено на архитектуре **MVVM**:

- **Model** — данные о пользователях и редактируемых объектах.
- **ViewModel** — бизнес-логика (авторизация, редактирование).
- **View** — SwiftUI-интерфейс: SignInView, DrawingScreen, SaveScreen и т.д.

---

## 🔐 Аутентификация

- Авторизация по email/паролю (с верификацией email)
- Авторизация через Google (Firebase OAuth)
- Сохранение сессии между запусками
- Сброс пароля по email
- Кнопка выхода (signOut)

---

## 🖌️ Функции редактора

- 📷 Загрузка изображений из галереи или камеры
- ✏️ Рисование с помощью PencilKit (поддержка Apple Pencil)
- 🔤 Добавление текста:
  - Цвет текста
  - Жирный шрифт
  - Перетаскивание текста
- 🔍 Масштабирование и поворот изображения (gesture support)
- 💾 Сохранение изображения в Фотоальбом
- 📤 Поделиться изображением через системный UI

🚀 Запуск проекта

Клонируйте репозиторий.
Откройте .xcodeproj в Xcode.
Установите зависимости через Swift Package Manager.
Убедитесь, что вы настроили Firebase и GoogleService-Info.plist.
Соберите и запустите на симуляторе или устройстве.
